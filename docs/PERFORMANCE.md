# Производительность (базовые замеры)

Машина разработки: Windows 11 Pro, Python 3.12.10, PySide6 6.8.3. Замер: `.venv\Scripts\python -m tools.perf_baseline`
(движок без окна, измеритель текста без Qt). Пороги в `tests/test_performance.py` заданы с большим запасом.

| Операция | 10 экранов / 200 экз. / 30 SVG | 50 / 1000 / 150 | 100 / 2000 / 300 |
|---|---|---|---|
| Сохранение .adsproj | 0,11 с | 0,43 с | 0,83 с |
| Открытие .adsproj | 0,05 с | 0,24 с | 0,46 с |
| Изменение мастера → все экземпляры | 0,04 с | 0,19 с | 0,37 с |
| Раскладка всех экранов | 0,01 с | 0,03 с | 0,05 с |
| Проверка проекта | 0,02 с | 0,10 с | 0,21 с |
| AI-экспорт (без превью) | 0,04 с | 0,18 с | 0,37 с |
| Запись ZIP | 0,02 с | 0,08 с | 0,15 с |

Интерфейс (проект 50 экранов / 1000 экземпляров): открытие ≈ 1,8 с, переключение экрана ≈ 0,3 с,
самопроверка собранной программы целиком ≈ 2,4 с. Запуск окна программы ≈ 2 с.

Найдено и исправлено на этапе 8: страница экспорта пересобирала пакет с превью на каждое изменение пункта
списка (57 с на 50 экранах) — теперь пересборка одна, с паузой 250 мс, а превью рисуются только при сборке.
