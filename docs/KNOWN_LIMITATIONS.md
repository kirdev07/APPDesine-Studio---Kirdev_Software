# Известные ограничения App Design Studio 1.3

## Общее
- Программа — студия дизайна: тестовый APK собирается из сгенерированного каркаса, а готовое приложение пишет
  разработчик или Claude Code по пакету AI-экспорта. EXE приложений не собирается.
- Интерфейс только на русском языке.
- Нет совместной работы, облака и учётных записей (это решение, а не недоработка).

## Отрисовка и предпросмотр
- Android рисуется движком студии — это приближение Jetpack Compose / Material 3: шрифты, тени, эффекты
  нажатия (ripple) и системные панели отличаются от устройства. Точного совпадения пикселей нет.
- Windows-предпросмотр рисует экран в рамке окна средствами студии; нативные виджеты Qt не используются.
- Касания имитируются мышью; мультитач (щипок, поворот двумя пальцами), датчики, вибрация и звук не
  моделируются. Экранная клавиатура — упрощённая русская раскладка без автозамены.
- Значения анимаций положения на другом устройстве применяются в координатах исходного макета.
- Под другое устройство экран перестраивается раскладкой (Auto Layout и привязки); элементы без привязок
  остаются на месте — проверка показывает, что вышло за экран.

## Редакторы
- SVG: поддерживаются пути, фигуры, заливка и обводка, viewBox; градиенты, фильтры, маски, текст в SVG и
  анимации SVG при импорте упрощаются или удаляются (о каждом упрощении сообщается).
- На таймлайне анимаций перетаскиваются только ключевые кадры; кривая cubic-bezier задаётся числами.
- Логика редактируется списком правил «событие → условие → действия»; карта переходов только показывает
  связи экранов (без редактирования узлами).
- Импорт из Figma и изображений в v1.0 не входит.

## Проверка и экспорт
- Контраст проверяется по цвету текста и непрозрачному фону под центром элемента; полупрозрачные слои и
  изображения под текстом не учитываются.
- Превью экранов в пакете — отрисовка студии, ориентир композиции, а не эталон пикселей.
- Ресурсы с запретом распространения не попадают в пакет — их нужно заменить в коде приложения.

## Material Design 3
- Схема цвета строится в пространстве CIELAB LCh — приближение HCT из material-color-utilities: тоны совпадают
  точно, оттенки и насыщенность вторичной, третичной и нейтральных палитр — близко, но не побитово.
- В предпросмотре живые компоненты меняют только вид; анимации самих компонентов (переезд бегунка и т. п.) и
  ввод в строку поиска не моделируются.
- Значки — собственный набор (21 шт.) в стиле Material, а не Material Symbols.
- Карточки, диалог, меню, нижний лист, боковое меню, строка поиска и элемент списка переводятся в Compose общей
  раскладкой (Column / Row), а не компонентами Card / AlertDialog / ModalBottomSheet.

## Эффекты и анимации
- У элемента на холсте видна одна графическая обработка: если задано размытие, тень не рисуется (в Android-проекте
  применяются обе). Тень на холсте — приближение возвышения Material 3, а не точная тень Android.
- Размытие (Modifier.blur) работает на Android 12+; на старых версиях элемент остаётся чётким. Размытие фона под
  элементом («стекло») не поддерживается — только размытие самого слоя.
- В Compose переводятся дорожки непрозрачности и положения; анимации размера, цвета, скругления и шрифта
  помечаются TODO. Переходы между экранами — затухание и сдвиги; общие элементы (shared elements) не создаются.

## Проект Android Studio из экспорта
- Это каркас для доработки: элементы вне Auto Layout размещаются абсолютными смещениями (`offset`), кроме
  растянутых по ширине и привязанных к низу экрана; тексты — прямо в коде; состояния своих компонентов, анимации,
  свайпы и SVG-изображения помечены `TODO`.
- Навигация — простой стек экранов с переходом «затухание»; Navigation Compose не используется, чтобы проект
  собирался с текущими версиями (AGP 8.13, Kotlin 2.2, Compose BOM 2025.09) без конфликтов зависимостей.
- Сборка APK использует уже установленные Android SDK, JDK (из Android Studio) и Gradle 8.13+ из кэша; если
  чего-то нет, программа сообщает об этом и предлагает сохранить проект для Android Studio. Подписанный
  релизный APK программа не собирает.

## Сборка и установка
- Распространяется как папка программы (portable ZIP): Python не нужен. Скрипт установщика Inno Setup
  (`packaging/AppDesignStudio.iss`) приложен, но на машине разработки Inno Setup не установлен, поэтому
  setup.exe не собирался.
- Подпись кода (Authenticode) не выполнялась: Windows SmartScreen может предупредить при первом запуске.
- Самопроверка выполнена на машине разработки в «чистом» окружении (без Python в PATH, путь с кириллицей);
  запуск на отдельной чистой виртуальной машине Windows 10 нужно провести вручную по `docs/RELEASE.md`.
