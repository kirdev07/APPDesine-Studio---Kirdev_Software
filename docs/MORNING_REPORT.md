Найдено и исправлено 17 ошибок (подробно — в CHANGELOG.md).

## Осталось (на ваше решение)

1. **Наведение мыши в Android** — на телефоне его нет; оставлено как есть (по вашему решению).
2. **Короткие видео «листанием вверх»**: листание страницами сейчас только вбок (HorizontalPager). Можно
   добавить вертикальное (VerticalPager) — небольшая доработка.
3. **Приложение Windows**: длинный текст при сужении окна не растёт по высоте (вторая строка обрезается);
   ползунок и индикатор — стандартного вида Qt, а не точная копия Fluent; у поиска нет значка лупы.
4. При добавлении панели навигации Windows на экран без неё содержимое сдвигается целиком и правые колонки
   становятся уже — их внутреннюю раскладку стоит проверить глазами (программа об этом предупреждает).
