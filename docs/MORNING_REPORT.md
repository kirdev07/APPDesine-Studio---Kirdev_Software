## На согласование (не сделано — нужен ваш выбор)

### Android
1. **Списки из данных (LazyColumn)** — сейчас повторяющиеся карточки выгружаются как отдельные элементы. Нужна
   модель «список + шаблон строки + данные» в редакторе. Крупная доработка (новый тип элемента).
2. **Наведение мыши** — на телефоне не бывает, правила «наведение» в Android не переносятся (так и задумано).
   Оставить как есть?
3. **Анимация цвета градиента** и анимация обводки — в коде помечаются TODO (Compose не анимирует их напрямую).
4. **Виджеты рабочего стола (Glance)**: ограничения самого Glance — нет произвольных фигур и теней. Оставить?
5. **Сохранение состояния при повороте** (`rememberSaveable` вместо `remember`) — небольшая доработка, могу
   сделать.
6. **Понятные маршруты ссылок** (`dostavka://korzina` вместо `dostavka://screen3`) — небольшая доработка.
7. **Подписи для TalkBack** (`contentDescription`, подпись нажатия) — пока в коде строкой, не ресурсом
   (не переводятся). Небольшая доработка.
8. **Material 1: переключатели** рисуются в стиле M3 — можно сделать «старый» вид.

### Windows
9. **Остальные события в приложении Windows** (двойное нажатие, удержание, наведение) — сейчас только в
   прототипе; после сохранения показывается их число.
10. **Окно приложения Windows фиксированного размера** (как в дизайне). Для растягиваемого окна нужна
    адаптивная раскладка — средняя доработка.
11. **Пункты панели навигации Windows** не связываются с экранами одной кнопкой (как нижнее меню Android) —
    только правилами «При нажатии». Небольшая доработка.

### Интерфейс (мелочи из проверки)

    ничего не делают — сделать неактивными.
13. Диалог темы в проекте только для Windows показывает варианты Android-приложения.
14. Предупреждения QPainter в журнале при маленьких миниатюрах (безвредно, но засоряет журнал).
15. «Все проекты» при 1280×800 тесноваты (1,5 ряда карточек), поле масштаба закрывает нижнее меню на холсте
    в режиме «вписать».
